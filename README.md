### 🛠️ What I do

I take products from the first commit to production: the mobile app, the API behind it, the admin panel, and the cloud infrastructure underneath. I've shipped 20+ apps and platforms across ed-tech, fintech, streaming, commerce, wellness and enterprise tools.

- 📱 **Mobile:** production Flutter apps built on BLoC, go_router, get_it, Dio, Freezed and Drift/Hive, with payments, deep links, localization and Firebase
- ⚙️ **Backend:** REST and gRPC services in **Go** (Gin, GORM), **TypeScript** (Hono, Express), **Python** (FastAPI, Django, Celery) and **Java 21**
- 🖥️ **Web & admin panels:** React and Next.js with Vite, Tailwind, shadcn/ui, TanStack Query and Zustand
- ☁️ **Cloud:** AWS (Lambda, S3, SQS, Kinesis, MediaConvert, CloudFront), Terraform, Docker and Serverless
- 🤖 **Agentic AI:** AI-agent platforms, LLM features in products, MCP servers, and job queues for generative media

### 🏗️ Things I've built

**AI & agents**
- **Agentic sales-ops platform:** ingests CRM and Microsoft 365 data for AI-driven sales workflows. Java 21 servlets, plain JDBC, PostgreSQL, React 19
- **AI-powered CRMs:** a Go/Gin/PostgreSQL/Redis backend with LLM-assisted features and 450+ tests, plus a React + shadcn/ui frontend
- **Generative-media tooling:** FastAPI + MongoDB backend, Redis job router and MCP server, self-hosted with Docker + Caddy
- **Lead-intelligence pipeline:** async Playwright scraper feeding structured company and job data into a CRM

**Products**
- **AI spoken-English coach:** Flutter app with voice recording, backed by a Go + gRPC + PostgreSQL service, plus a Next.js marketing site
- **Streaming platform:** a CMS for ingestion, publishing and merchandising (React 19 + Hono on Lambda, Terraform, Playwright e2e), a MediaConvert/SQS/Kinesis video pipeline with CloudFront signed URLs, and an Android TV codec diagnostics app
- **Mindfulness & journaling app:** Flutter client, plus a full rewrite of its backend from Django to Go with complete feature parity
- **Fintech:** a cross-border remittance app and backend, plus a mutual-fund distributor app
- **Commerce:** FastAPI + Celery backend, React admin, and a Flutter shopping app with Razorpay checkout
- **Internal tools:** a resource-management system for engineering teams, a seller price-intelligence dashboard, and an S3 archiver for ad data
